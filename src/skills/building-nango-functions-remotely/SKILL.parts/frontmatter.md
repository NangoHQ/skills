Use when creating, updating, validating, testing, or deploying Nango syncs remotely via API or single-file payloads. The remote API does not accept tools yet; build tools with building-nango-functions-locally. This content overlaps with building-nango-functions but adds remote API workflow details, so load this instead of building-nango-functions whenever remote, API, /functions/compile, /functions/dryruns, /functions/deployments, or no local project workflow is indicated.
