# Build Nango Functions Remotely
Build Nango syncs without a checked-out Nango project by sending a single-file TypeScript function to Nango's `/functions/compile`, `/functions/dryruns`, and `/functions/deployments` APIs.

The remote functions API does not accept tools yet. Build a tool (`createTool()`, `references/tools.md`) with `building-nango-functions-locally`.
